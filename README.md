
# Aplikasi OCR Berbasis AI

## Deskripsi
Aplikasi OCR (Optical Character Recognition)
digunakan untuk mengenali dan mengekstrak teks
dari gambar menggunakan teknologi Artificial
Intelligence dan Deep Learning.

## Teknologi
- Python
- Streamlit
- EasyOCR
- PyTorch
- NumPy
- Pillow

## Fitur
1. Upload gambar.
2. Pengenalan teks otomatis.
3. Menampilkan hasil ekstraksi.
4. Menampilkan tingkat keyakinan AI.
5. Download hasil teks.

## Cara Menjalankan

1. Install library:

   pip install -r requirements.txt

2. Jalankan aplikasi:

   streamlit run app.py

3. Buka aplikasi melalui browser.
